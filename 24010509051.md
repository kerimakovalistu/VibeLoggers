## 📌 Projenin Amacı ve Kısa Açıklaması
VibeLoggers, kullanıcıların o anlık duygularını (vibe), ne hissettiklerini ve buna neyin sebep olduğunu kayıt altına alabildikleri (loglamak) interaktif bir duygu günlüğü uygulamasıdır. Kullanıcılar kendi duygularını paylaşmanın yanı sıra, genel akış (feed) ekranında dünyadaki diğer kullanıcıların neler hissettiğini anonim olarak inceleyebilir ve onlara etkileşim gönderebilir. Uygulamanın amacı bireylerin içsel durumlarını dijital bir dille dışa vurmaları ve kolektif bir empati alanı oluşturmaktır.

## 🛠️ Kullanılan Teknolojiler / Kütüphaneler
- **Frontend (Arayüz):** React, Vite, Tailwind CSS, Lucide React (İkonlar), React Router DOM, motion (animasyonlar).
- **Backend (Arka Uç):** Node.js, Express.js.
- **Veritabanı ve ORM:** MySQL, Prisma ORM.
- **Güvenlik / Şifreleme:** bcryptjs (Şifre hashleme).

## 🚀 Kurulum Adımları
Bu proje kendi bilgisayarınızda (yerel ortamda) çalıştırılabilir şekilde tasarlanmıştır.

### Gereksinimler:
* Node.js (v18 veya üzeri)
* MySQL Sunucusu (XAMPP veya MySQL Installer ile kurulmuş)
* Git (isteğe bağlı)

1. **Projeyi Bilgisayarınıza İndirin:**
   Projeyi bir ZIP dosyası veya RAR olarak indirdiyseniz, bir klasöre çıkartın. Terminalde proje klasörünün içine girin (`cd vibeloggers` benzeri).
2. **Bağımlılıkları Yükleyin:**
   Terminali açıp gerekli kod modüllerini indirin:
   ```bash
   npm install
   ```
3. **Veritabanını Hazırlayın:**
   MySQL veritabanınızın (XAMPP vb.) çalışır durumda olduğundan emin olun. Şimdilik herhangi bir kod yazmanıza gerek yok, uygulama kurulumu kendisi yapacaktır (Eğer isterseniz phpMyAdmin üzerinden `vibeloggers` adında boş bir veritabanı açabilirsiniz).
4. **Uygulamayı Başlatın (Geliştirici Modunda):**
   ```bash
   npm run dev
   ```
   Bu komutla uygulama `http://localhost:3000` adresinde hayat bulacaktır.

## 📖 Çalıştırma / Kullanım Talimatları
1. Tarayıcınızda `http://localhost:3000` adresine gittiğinizde, sistem veritabanı ayarlarının boş olduğunu algılayacak ve sizi otomatik olarak **Sistem Kurulumu (/setup)** ekranına yönlendirecektir.
2. Açılan ekranda veritabanı bağlantı dizgenizi girin (Örn: `mysql://root:@localhost:3306/vibeloggers`). 
3. Sistem yönetim paneline erişim sağlayacak **İlk Yönetici (Master Admin)** hesabını da aynı form üzerinden oluşturun.
4. "Sistemi Kur ve Hesabı Oluştur" butonuna tıkladığınızda kurulum yapılır ve kısa bir süre içerisinde sisteme otomatik geçiş yaparsınız (Not: Ekran yenilenmezse lütfen CTRL+F5 ile yenileyin).
5. Oluşturduğunuz hesapla giriş yaptıktan sonra duygularınızı girebilir, diğer kullanıcıların paylaşımlarını (`/feed` rotasında) inceleyebilir veya `Admin Paneli` sekmesinden içerik yönetimi/logları görebilirsiniz.
